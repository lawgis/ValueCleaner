about=Value Cleaner groups values in a text field that are really the same thing written differently, for example "Kaduna", "kaduna " and "Kadunna". It shows each group with feature counts and proposes the most common spelling as the correct one, which you can change. Values containing different numbers (Zone 1 and Zone 2) are never grouped. Apply the fixes to a new layer, leaving the original untouched, or edit the layer in place as a single undo step. Useful for any data that was typed by hand, collected in the field or merged from several sources.
